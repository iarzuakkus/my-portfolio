# İ. Arzu Akkuş — Kişisel Portfolyo

Yapay zekâ, doğal dil işleme ve veri odaklı yazılım çalışmalarını sunan kişisel
portfolyo sitesi.

## Geliştirme

```bash
npm install
npm run dev
```

## Proje yapısı

- `src/components`: Tekrar kullanılabilir arayüz ve yerleşim bileşenleri
- `src/sections`: Sayfanın bağımsız içerik bölümleri
- `src/data`: Portfolyo içeriklerinin merkezi veri kaynağı
- `src/styles`: Tasarım değişkenleri, sıfırlama ve genel stiller
- `src/assets`: Görsel ve ikon dosyaları
